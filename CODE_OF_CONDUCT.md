# Code of Conduct

Aurora started as a project for one living room. If you're here, you're a
guest in that living room — and honestly, we're glad you came.

## The short version

**Be kind. That's basically it.**

## The slightly longer version

- Be welcoming. Someone's first issue or PR might be their first ever —
  remember what that felt like.
- Disagree about code, not about people. "This function has a bug" is
  useful; "you are a bug" is not.
- Nobody here is on the clock. Reviews, replies and fixes happen when life
  allows. Patience is part of the deal.
- Questions are welcome, including the "obvious" ones. The docs exist
  because someone asked.
- No harassment, no hate, no creepiness — toward anyone, for any reason.
  This is the one rule with no wiggle room.

## If something goes wrong

If someone makes you feel unwelcome here, open an issue or use GitHub's
report tools, and it will be taken seriously. Reports stay private.

If you're the one who messed up: a genuine "my bad" goes a long way.
We've all been there.

## The spirit of the thing

This project is about watching movies with the people you like, on software
made with care. Keep that energy in the issues too. 🍿
