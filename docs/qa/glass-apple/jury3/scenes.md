# The scenes

Each scene is one moment of the website photographed three times — the same data, the same position, the sky and every animation held still — once with each of 3 looks for the glass. `scene-NN-A.png`, `scene-NN-B.png`, `scene-NN-C.png` are the whole screen; `scene-NN-A-crop.png`, `scene-NN-B-crop.png`, `scene-NN-C-crop.png` are the glass parts of the same photographs at twice their size on the page, stacked in the order listed. Which look carries which letter changes from scene to scene.

The frames of Apple's own glass are the ones in `../jury/` (`reference-1-…`, `reference-2-…`).
